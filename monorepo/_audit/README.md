# Audit: динамический workflow проверки монорепо

Эта папка — **служебный инструментарий** для перепроверки всего монорепо. Не часть продуктовой структуры (отсюда префикс `_`).

## Что внутри

```
_audit/
├── workflow.yaml         декларативное описание pipeline
├── scripts/              исполняемые скрипты
│   ├── 00_inventory.py
│   ├── 01a_check_structure.py
│   ├── 01b_check_links.py
│   ├── 02_coverage_88.py
│   ├── 03_extract_facts.py
│   ├── 04_consistency.py
│   ├── 05_fidelity_stub.py
│   ├── 06_completeness_stub.py
│   └── 99_run_all.py     оркестратор всех фаз
├── reports/              выход скриптов (Markdown + JSON)
└── queues/               рабочие очереди (repair, enrich, create)
```

## Запуск

```bash
cd monorepo/_audit
python3 scripts/99_run_all.py
```

Каждый скрипт можно запускать отдельно. Скрипты **только читают** репо и пишут в `reports/`/`queues/`. Они **не модифицируют** ни одного существующего файла.

## Фазы

| Фаза | Скрипт | Стоимость | LLM? |
|------|--------|-----------|------|
| 0 — Инвентаризация | 00_inventory.py | ~0 c | нет |
| 1a — Структура | 01a_check_structure.py | ~0 c | нет |
| 1b — Ссылки | 01b_check_links.py | ~0 c | нет |
| 2 — Покрытие 88 тем | 02_coverage_88.py | <1 c | нет (детерм.) |
| 3 — Извлечение фактов | 03_extract_facts.py | <1 c | нет (regex) |
| 4 — Согласованность | 04_consistency.py | <1 c | заглушка для LLM |
| 5 — Сверка с первоисточниками | 05_fidelity_stub.py | заглушка | да (будет) |
| 6 — Полнота chat_export | 06_completeness_stub.py | заглушка | да (будет) |
| Оркестратор | 99_run_all.py | сумма | — |

## Итоговый отчёт

`reports/REPORT.md` — сводный дашборд по 6 осям качества.

## Принципы

1. **Сначала бесплатное** — детерминированные проверки гонять всегда
2. **ИИ только по флагам** — фазы 4-6 включаются для проблемных файлов
3. **Никаких автоправок без подтверждения** — все правки складываются в `queues/autofix.json` и применяются отдельным скриптом
4. **Воспроизводимо** — `99_run_all.py` можно гонять после каждого изменения
