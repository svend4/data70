# Машинный health-аудит data70 (sandbox-изоляция, слой 3)

_Метод: 180 портированных lorenzo-скриптов прогнаны в **sandbox-копии** контента.
Реальные карточки data70 не тронуты ничем. Диагностические отчёты извлечены в
`sandbox_health/`._

## Как сработала изоляция (слой 3)

```
monorepo/ (реальный, 220 карточек)
   │ copytree только контентных папок (без _audit/)
   ▼
/tmp/textkit_sandbox_XXX/  ← скрипты пишут СЮДА
   │ 180 скриптов: 158 ok / 20 err / 2 timeout
   │ сгенерировано 105 отчётов + загрязнили sandbox-карточки
   ▼
извлечены 20 диагностических отчётов → sandbox_health/
   │
   ▼
sandbox удалён; реальный monorepo НЕ изменён ✓
```

Проверка: `git status` после прогона — карточки 01-10/super **не в списке
изменений**. Слой-3 sandbox решил проблему побочных эффектов из прошлого прогона.

## Что нашли диагностические отчёты

### Структура (STATS)
- Разделов: 14 контентных + подпапки
- Карточек: 220, слов: ~134K (без obsidian-зеркала)
- Самые объёмные разделы: 02_ai_agents (28 файлов), 06_business_funding (24)

### Языки (LANGUAGE_STATS)
- RU (≥80% кириллица): 45 файлов
- EN (≥80% латиница): 9 файлов
- Большинство карточек смешанные RU+EN (термины) — соответствует
  `naming_conventions.md` (документация на русском, термины на английском)

### Изолированные карточки (ORPHANS) — единственная реальная находка
~15 карточек помечены как «изолированные» (нет входящих markdown-ссылок):
- 00_index: 6, 04_robotics_caremate: 2, 06_business_funding: 2, остальные по 1

**Причина:** мои секции «## Связи» используют **текстовые** ссылки
(`01_social_law/02_widerspruch_templates`), а не markdown-ссылки
(`[...](../...)`). Скрипты считают только markdown-формат.

**Это валидная рекомендация:** если превратить текстовые «Связи» в markdown-ссылки,
карточки станут полноценным графом, и orphans исчезнут. Совпадает с тем, что
CardEnvelope lorenzo (типизированные edges) — образец для улучшения data70.

### Читабельность (READABILITY)
- FRE = 0 для большинства (формула не настроена на русский) — метрика
  неинформативна для русскоязычного контента
- Средняя длина предложения: 8-38 слов (catalog_88 — самые длинные, ожидаемо
  для таблиц)

## 20 извлечённых отчётов

`sandbox_health/`: health, metrics, scoring, stats, kpi, readability, complexity,
vocabulary, language_stats, orphans, empty_sections, content_gaps, heading_audit,
missing, density, staleness, word_freq, topic_model, consistency, coverage.

Все очищены от lorenzo-вставок (`<!-- summary -->`, «проекта Lorenzo» и т.п.).

## Сводка ошибок прогона

158 ok / 20 err / 2 timeout / 0 crash (см. `full_machine_audit.json`).
20 ошибок — те же категории, что в прошлый раз (lorenzo-пути, argparse-аргументы,
внешние зависимости, внутренние утилиты lorenzo). 2 timeout — `watch`/`watcher`
(long-running демоны, не предназначены для batch).

## Единственная практическая рекомендация для data70

Превратить текстовые «Связи:» в markdown-ссылки → устранит 15 «orphans» и даст
полноценный граф знаний. Это можно сделать скриптом (механически) — но это
**изменение карточек**, поэтому только с твоего согласия.
